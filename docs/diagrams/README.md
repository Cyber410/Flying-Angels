# Use-case code diagrams

Open [use-case-code-diagrams.drawio](use-case-code-diagrams.drawio) in diagrams.net. This single file contains ten editable pages: seven earlier implemented diagrams and the three Sprint 4 code designs. The SVG files below are image exports of the individual pages.

## Sprint 4 code designs

| Use case | Image |
| --- | --- |
| Competition Programs: Draft, Publish and Athlete Schedule | [SVG](14-competition-programs.svg) |
| In-App Notifications and Scheduled Reminders | [SVG](15-in-app-notifications.svg) |
| Role-Based Dashboards and Shared Navigation | [SVG](16-role-based-dashboards.svg) |

Each diagram shows frontend, HTTP API, controller/security, service, repository, data model and response layers, plus sunny-day and rainy-day paths. **E** (green) identifies existing code, **P** (purple) identifies proposed components/contracts, and **EXTEND** (amber) identifies existing code with planned changes. Solid arrows trace requests/data access; dashed arrows trace responses. Filename numbers continue the image sequence and are not use-case IDs.
